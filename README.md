# Per-App & Permanent Screen Lock Android App 📱

แอพพลิเคชัน Android สำหรับล็อคหน้าจอเป็นแนวตั้งหรือแนวนอน **แบบถาวร (Permanent Lock)** และ **แยกตามรายชื่อแอพ (Per-App Screen Orientation)**

## ✨ คุณสมบัติใหม่ในเวอร์ชัน 1.2.0 (แก้ปัญหาล็อคหน้าจอไม่ได้)
1. 🔒 **ระบบ WindowManager Overlay Engine**: บังคับทิศทางหน้าจอข้ามแอพอื่นได้จริง (Override ทุกแอพแม้ว่าแอพนั้นจะสั่งล็อคแนวตั้งไว้ในตัว)
2. 🎛️ **โหมดล็อคหน้าจอหลัก (Master Modes)**:
   - 🎯 **ล็อคตามแอพที่เลือก**: ตรวจจับแอพที่กำลังเปิดใช้งาน และปรับทิศทางตามที่ตั้งค่าไว้
   - 🔒 **ล็อคแนวตั้งถาวร (Force Portrait)**: ล็อคแนวตั้งทุกแอพตลอดเวลา
   - 🔄 **ล็อคแนวนอนถาวร (Force Landscape)**: ล็อคแนวนอนทุกแอพตลอดเวลา
   - 🌐 **หมุนตามเซนเซอร์อัตโนมัติ (Force Auto)**: หมุนตามเซนเซอร์เครื่องรอบทิศ
   - ⏹️ **ปิดการทำงาน (Stop)**: คืนค่าเดิมของระบบ
3. 🔔 **แถบควบคุมด่วนบน Notification Bar**: ปรับเปลี่ยนทิศทางหน้าจอได้ทันทีจากแถบแจ้งเตือนโดยไม่ต้องสลับเข้าแอพ
4. 📱 **ระบบเลือกแอพที่แม่นยำขึ้น**: ดึงรายชื่อแอพทั้งหมดในเครื่อง รองรับ Android 11–14+ พร้อมค้นหาและกดเลือกได้ทันที

## 🔑 สิทธิ์ที่จำเป็นในการทำงาน (สำคัญมาก)
เพื่อให้แอพสามารถบังคับทิศทางหน้าจอของแอพอื่นได้ กรุณากดเปิดสิทธิ์ในหน้าแอพให้ครบ 3 ข้อ:
1. **แสดงทับแอพอื่น (Display Over Other Apps)**: *จำเป็นที่สุด* เพื่อสร้างเลเยอร์บังคับการหมุนหน้าจอ
2. **แก้ไขการตั้งค่าระบบ (Modify System Settings)**: เพื่อเปลี่ยนโหมดการหมุนของระบบเครื่อง
3. **บริการการเข้าถึง (Accessibility Service)**: เพื่อตรวจจับว่าขณะนี้ผู้ใช้เปิดแอพไหนอยู่ (เฉพาะเมื่อใช้โหมดแยกตามแอพ)
