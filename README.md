# Per-App Screen Lock Android App 📱

แอพพลิเคชัน Android สำหรับล็อคหน้าจอเป็นแนวตั้งหรือแนวนอน **แยกตามรายชื่อแอพอย่างถาวร (Per-App Screen Orientation)**

## ✨ คุณสมบัติใหม่ในเวอร์ชัน 1.1.0
- 📱 **เลือกแอพในเครื่องได้ทั้งหมด**: แสดงรายการแอพที่ติดตั้งไว้ในเครื่องพร้อมไอคอนและชื่อแอพ
- 🔒 **ล็อคหน้าจอถาวรตามแอพ**: กำหนดให้แต่ละแอพล็อคเป็นแนวตั้ง (Portrait), แนวนอน (Landscape) หรือค่าเดิมอัตโนมัติ
- ⚡ **Real-time App Detection**: ใช้ Accessibility Service ตรวจจับการเปิดแอพได้ทันที แม่นยำ ไม่เปลืองแบตเตอรี่
- 🎛️ **Quick Controls**: สั่งล็อคแนวตั้ง/แนวนอน/หมุนตามเครื่องได้ทันทีจากหน้าแอพ
- 🔍 **ค้นหาแอพได้รวดเร็ว**: ค้นหาตามชื่อแอพหรือชื่อ Package Name

## 🔑 สิทธิ์ที่จำเป็นในการทำงาน
1. **Modify System Settings (แก้ไขการตั้งค่าระบบ)**: จำเป็นสำหรับสั่งล็อคและเปลี่ยนโหมดการหมุนหน้าจอของเครื่อง
2. **Accessibility Service (บริการการเข้าถึง)**: จำเป็นสำหรับตรวจจับเมื่อผู้ใช้สลับหรือเปิดใช้งานแอพต่างๆ
